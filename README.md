# Automotive AI Customer Agent

End to end conversational AI assistant for an Automotive OEM customer lifecycle, built for the AI Solutions Engineer assessment.

The application uses an AI agent with tool calling to interact with Zoho CRM and support customers across four lifecycle stages:

1. New Lead
2. Ongoing Sales Pipeline
3. Booked Vehicle
4. Post Purchase Service

## Architecture

```text
React Frontend
      |
      v
FastAPI Backend
      |
      +---- Session State
      |
      +---- Groq LLM
      |       |
      |       +---- Vehicle Information
      |       +---- Lead Creation
      |       +---- Deal Search
      |       +---- Booking Search
      |       +---- Service Case Creation
      |
      +---- CRM Service Layer
                  |
                  v
              Zoho CRM
```

The backend is implemented without LangChain so that tool orchestration remains explicit and easy to understand.

## Customer Lifecycle Workflows

### 1. New Lead

The assistant handles visitors who are interested in a vehicle and want to explore features or a test drive.

It collects:

* Full name
* Phone number
* Email
* Preferred city
* Vehicle model
* Variant

The information is then stored as a Lead in Zoho CRM.

The initial vehicle interest and test drive related information are captured as part of the Lead stage.

### 2. Ongoing Sales Pipeline

For customers who have progressed further in the sales process, the assistant retrieves an existing Zoho Deal using the Deal ID.

The Deal is used as the source of truth for ongoing sales and test drive information, including details such as:

* Sales stage
* Vehicle
* Test drive details
* Dealer
* Closing information
* Deal amount

This separates initial Lead capture from the ongoing sales pipeline represented by a Deal.

### 3. Booked Vehicle

For booked vehicles, the implementation represents the booking using a Closed Won Deal.

The Deal description can contain:

* Booking ID
* Vehicle
* Variant
* Booking status
* Allocation stage
* VIN status
* Delivery timeline
* Balance payment information

The assistant retrieves the Deal using its Deal ID and uses the CRM response to answer booking related questions.

### 4. Post Purchase Service

The assistant supports service and maintenance requests by collecting information such as:

* Registration number
* Service or issue type
* Issue description
* Odometer reading
* Preferred service center
* Preferred appointment date

It then creates a Case in Zoho CRM and returns the Case ID generated by Zoho.

Where a matching Contact is available, the Case can also be linked to that Contact.

## AI Agent Design

The agent receives the conversation history together with the available tool definitions.

Based on the customer's request, the LLM determines whether to:

* Answer using the vehicle catalog
* Create a new Lead
* Retrieve an existing Deal
* Retrieve a booked vehicle record
* Create a service Case

CRM information is treated as the source of truth. The agent is instructed not to invent CRM records, booking information, test drive details, VINs, delivery dates, or service Case IDs that are not returned by the corresponding tool.

## Setup

### Backend

Create and activate a Python virtual environment, then install the dependencies:

```bash
pip install -r backend/requirements.txt
```

Configure the backend `.env` file using the variables provided in:

```text
backend/.env.example
```

The Zoho OAuth credentials and Groq API key must be provided through environment variables.

Start the backend:

```bash
uvicorn app.main:app --reload --port 8000
```

### Frontend

Install the frontend dependencies:

```bash
cd frontend
npm install
```

Configure:

```text
frontend/.env
```

with:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

Start the frontend:

```bash
npm run dev
```

## Security

Secrets are not stored in the repository.

The following should remain in local `.env` files and must never be committed:

* Zoho client secret
* Zoho refresh token
* Groq API key

Only `.env.example` files containing placeholder values should be committed.
